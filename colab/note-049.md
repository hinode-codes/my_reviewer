## PROGRAM FLOW - DSTC BRANCH TRAINING (CASHIER)

* To be shown to the Branch Manager / Assistant Branch Manager on duty

### DAY 1-4

> Branch officer provides a guided branch tour and introduces trainee to branch employees
> Orientation of General / Specific House Rules
> Types of offenses
> Trainee will familiarize themselves w/ items copied (CD, PK I, II, III, SGC) including other forms and dosage

### DAY 5

> Practice using Takeord stations and POS Machine
> Practice preparing order using takeord slips
> Trainee observes assigned branch personnel applying standard selling / cashiering procedure (GREAT CARE) for PA & Ca.
> Practice GREAT CARE w/ officer.

### DAY 6 ONWARDS

> Actual cashiering w/ BM / ABM supervision
> Displaying, forwarding of stocks, cleaning of assigned gondola
